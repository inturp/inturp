أوامر فحص MacBook قبل الشراء

افتح Terminal، واضغط «نسخ»، ثم الصق الأمر. جميع الأوامر التالية للاستعلام فقط ولا تحتاج إلى تثبيت برامج.

1. المواصفات والبطارية والنظام

يعرض المعالج والرام ومعلومات البطارية ودورات الشحن وإصدار macOS.

system_profiler SPHardwareDataType SPPowerDataType; sw_vers

2. حالة التخزين والقرص

يعرض معلومات SSD وحالة SMART إن كانت متاحة. عدم ظهور خطأ لا يضمن سلامة القرص بالكامل.

diskutil info disk0 | grep -E 'Device / Media Name|Disk Size|SMART Status|Protocol'; diskutil list

3. إدارة الشركات MDM

يفحص حالة التسجيل الإداري الحالية. ظهور No لا ينفي تسجيل الجهاز في Apple Business Manager أو ظهور Remote Management بعد المسح.

profiles status -type enrollment; profiles list

4. إعدادات الأمان

يعرض حالة SIP وFileVault. لا يثبت هذا الأمر ملكية الجهاز أو غياب Activation Lock.

csrutil status; fdesetup status

5. سجلات الأعطال

يبحث عن تقارير Kernel Panic وأسباب إيقاف التشغيل المسجلة خلال آخر 7 أيام. قد تكون السجلات ناقصة أو محذوفة.

find /Library/Logs/DiagnosticReports "$HOME/Library/Logs/DiagnosticReports" -maxdepth 1 \( -iname '*panic*' -o -iname '*kernel*' \) -print 2>/dev/null | head -20; log show --last 7d --style compact --predicate 'eventMessage CONTAINS[c] "Previous shutdown cause"' 2>/dev/null | tail -15

6. أمر شامل سريع

يجمع نتائج الفحوص الأساسية السابقة بأمر واحد. استخدمه إذا وقتك محدود، وصوّر النتائج بعد إخفاء الرقم التسلسلي والمعلومات الشخصية.

echo '=== HARDWARE & BATTERY ==='; system_profiler SPHardwareDataType SPPowerDataType; echo '=== STORAGE ==='; diskutil info disk0 | grep -E 'Device / Media Name|Disk Size|SMART Status|Protocol'; echo '=== MDM ==='; profiles status -type enrollment; profiles list; echo '=== SECURITY ==='; csrutil status; fdesetup status; echo '=== MACOS ==='; sw_vers

تنبيه ضروري: لا يوجد أمر Terminal محلي يضمن عدم وجود Activation Lock أو تسجيل شركة. قبل الدفع اطلب من البائع مسح الجهاز رسميًا، ثم أكمِل إعداده متصلًا بالإنترنت وتأكد من عدم ظهور Activation Lock أو Remote Management.
